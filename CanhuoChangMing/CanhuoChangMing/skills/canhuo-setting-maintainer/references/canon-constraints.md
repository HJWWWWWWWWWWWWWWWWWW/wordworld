# 全局硬约束

## 世界与行政

- 世界名：玄尘大陆。
- 中央世俗政权：大燧王朝，名义统御十二州。
- 十二州固定为：燧京、青、北寒、南疆、渡厄、云麓、楚南、东海、西陵、赤炎、沧澜、黑沙。
- 中州、楚州、雍州及北境三州只能作为旧称、俗称或军区称谓。
- 归墟魔主是归墟借众生绝望形成的现世意志，不是固定肉身魔王。

## 九灯与遗物

- 九灯固定为天、青、寒、南、厄、云、楚、海、陵。
- 灰炉镇地下是青灯副阵旧节点，不是独立主灯。
- 十二遗物负责定位、稳定、修补与见证，不能替代各灯传承者施展催灯秘法。
- 命火是性命本源，不是高阶修炼者通用能力；须掌握深层传承秘法才可能燃动，秘法可学但代价不可免。
- 九灯各有独立传承与秘法；适格者、修为、秘法与封住归墟的强烈意愿共同决定灯是否回应。
- 残火源于九灯初次同应时遗下的无主余焰，内含历代适格者不完整且互相矛盾的意愿碎片；它不属于皇室、林家或单一血脉，也不是第十盏灯。
- 长明残灯只是残火曾经的容器与传递之物。真火后来封入无灯窟，灰炉只留无力冷灰形成的“引灰”。

## 主要身份

- 林烬故乡是青州灰炉镇。
- 白璃出生于南疆白川部。
- 晏玄烈是当代皇帝；燧武帝只指开国皇帝。
- 晏长昭是监国长公主，不是太子。
- 大燧当前没有正式太子。

## 终局硬约束

- 全书采用九部正式章节卡，当前为第1章至第1250章。
- 第八部《归墟前夜》结束时，道路已经打开，林烬仍在撤离线尽头，核心点火位空着；不得让他用对白解释态度。
- 残火每次真正显现必须同时给出真实力量与不可逆代价；力量足以越过林烬当时境界、改变现场，代价落在血肉、脏器、知觉、行动功能、具体记忆或寿数上。不得只写受苦而没有力量，也不得建立可计算兑换表。
- 林烬境界固定为：第一部启息初入，第二部启息圆满，第三部前段通脉，第六部化渊池照魂，第九部封印前以余火域立域，封印时承接九灯与界线进入承天。
- 修士凭自身灵根、内景与息律即可施术、起域，外物不是必需条件。普通外物只能辅助承应；灵器可以放大、稳定或凭器中积存、器灵和预炼术式独立发挥有限作用。林照山的承火锤、炉灰和人间微火是在余火域展开后响应并放大它，不是凑齐后才能启动。
- 第九部完成立域、承天、归墟封印与结局。承天依赖九位传承者已经催动的九灯、十二遗物及各地共同维持的外部秩序，不使林烬成为第十盏灯。
- 林烬封印归墟后随一粒微小火花失踪；不得确认火花归属、死亡、复活、转世或归来。
- 谢观玄在承天封印引发的归墟倒卷中明确死亡；其死亡不等于归墟现世意志或终焉思想消失，也不得作为洗白。
- 九灯只是暂时重亮；是否稳定、权力是否重新集中不作定论。
- 不详细展开战后治理。
- 小满不为林烬写下结论，保留空白页。
- 最后炉火可解释为余炭、地火、陌生人添火或林烬痕迹。
- 最后一句固定为：火还没有灭。
