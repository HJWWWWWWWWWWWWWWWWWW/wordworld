# 《残火长明》伏笔分层与回收表

## 一、核心谜题释放节奏

| 结构区间 | 读者能够确认的真相 | 仍然保留的问题 |
|---|---|---|
| 第一部 | 灰炉镇灾变不是意外；林烬只留下无人知晓的引灰 | 谁下令、无灯梦为何反复 |
| 第二部 | 玄阳学院正在筛选遗物适格者 | 学院为谁服务 |
| 第三部 | 旧盟历史被删改；林烬秘密承接残火，叶无舟只怀疑 | 残火是什么、为何会带来陌生片段 |
| 第四部 | 妖族与南越同样参与过旧盟守封；沈青萝先确认残火，部末核心三人陆续知情 | 长明残灯为何只剩冷灰 |
| 第五部 | 王朝以边境和军民承担守封代价；顾长风得知残火秘密 | 皇室是否掌控九灯，外界传闻为何互相矛盾 |
| 第六部 | 灯奴、祭器、送厄、实验属于同一套强制调用逻辑；外界仍不能坐实残火 | 九灯各脉秘法能否脱离中央重新接续 |
| 第七部 | 皇城灯讯公开残火存在；祖殿旧图证实它不属于皇室 | 初次同应遗下的余焰为何能牵动九灯 |
| 第八部 | 九灯可以主动互认，林烬可以拒绝点火 | 替代方案能否持续 |
| 第九部 | 林烬在替代方案被真实尝试后选择点火 | 他的选择如何不被新权力利用 |

## 二、主要伏笔表

| 伏笔 | 首次埋设 | 中段推进 | 最终回收 |
|---|---|---|---|
| 灰炉镇铜梆 | 第一篇灾前报更异常 | 云灯档案显示警报被压下 | 终章废墟中无风轻晃，不确认由谁重新挂起 |
| 林家炉火 | 林照山教林烬守炉 | 证明灰炉民间守炉旧线曾客观维持青灯副阵 | 林烬以内景立成余火域，承火锤、炉灰与人间微火随后响应放大，不获得血脉特权 |
| 引灰与冷灰 | 前两部只有可误认的无灯梦与错路感 | 第三部无灯窟见到同源冷灰；第六、七部残卷证实真火与灯壳曾被分藏 | 证明长明残灯只是容器，灰炉无真火，林烬并非血脉继承 |
| 残缺意愿 | 第三部用火时出现无法解释的半个动作与陌生疼痛 | 与白川骨笛、云灯残卷、祖殿阵图互证，碎片彼此仍有冲突 | 九灯分别起灯后，残火借历代碎片牵起共鸣；不出现完整残魂讲解 |
| 残火知情边界 | 叶无舟只疑焦痕 | 沈青萝第一个确认；小满、白璃、萧寒衣、顾长风先后得知并遮掩 | 第七部皇城公开存在，具体代价直到终局仍不对外完整公开 |
| 适格者编号 | 黑松岭灯尸 | 学院试炼名单与灯籍对应 | 九灯必须由适格者借各脉秘法催动，但适格不等于阵图可以直接调用此人 |
| 无名册 | 灰炉逃路残页 | 小满记录陆平、顾长风与各州死者 | 终局作为十二遗物之一记录启动与拒绝 |
| 镇魂灯 | 遗物试炼 | 显示旧盟献祭命令存在多版本 | 成为公开旧史的辅助证据，不代替十二遗物 |
| 白川骨笛 | 白璃血脉异动 | 白川归名与南灯旧誓 | 唤醒南灯主动回应 |
| 寒关铁令 | 顾长风残缺军令 | 寒荒停战证明关外旧誓 | 维持终局北线撤离 |
| 楚天璧 | 楚明霜家族身份 | 历代祭器名册 | 切断楚灯血脉强制权限 |
| 云灯删档痕迹 | 雨夜行灾许可 | 各州命令来自同一中央权限 | 终局校验各地真实意愿 |
| 观海镜篡改 | 东海禁料航线 | 海听澜公开部分记录 | 定位九灯偏移 |
| 沈青萝魂毒 | 陆平救治 | 南疆疫潮、渡厄莲延缓 | 终局前救人后死亡，魂毒代价不消失 |
| 断风峡 | 北境撤离 | 萧寒衣旧案与镇渊剑 | 萧寒衣燃雪断后 |

## 三、伏笔管理规则

同一核心伏笔至少经过“出现、误读、验证、回收”四个阶段。

伏笔回收必须改变人物选择或局势，不能只提供背景知识。

若删除或移动篇章，必须同步检查该篇承担的伏笔是否失去中段推进。

终局不得突然新增能够解决九灯危机的遗物、血脉或规则。
